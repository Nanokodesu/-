# Cesium 坐标系统
**WGS-84 坐标系：**
以地球质心为坐标原点的地心坐标系，在Ceisum中以弧度或经纬高度（Cartographic类）表示，默认单位为弧度

**世界坐标系：**
笛卡尔空间直角坐标系（Cartesian3），以椭球体中心点为原点的空间直角坐标系中的某一个点的坐标（x, y, z）

**平面坐标系：**
二维笛卡尔直角坐标系（Cartesian2），用来描述屏幕坐标系（x, y）

# 相机事件
很重要
目前我们看到的视角，是架设相机的视角


**主要相机事件类型**

|   |   |
|---|---|
|LEFT_DRAG|按住鼠标左键，然后移动鼠标并松开按键|
|RIGHT_DRAG|按住鼠标右键，然后移动鼠标并松开按键|
|MIDDLE_DRAG|按住鼠标滚轮，然后移动鼠标并松开按键|
|WHEEL|滚动鼠标滚轮|

**Cesium默认操作模式**

|                 |       |         |       |
| --------------- | ----- | ------- | ----- |
| 操作              | 3D 视图 | 2.5D 视图 | 2D 视图 |
| LEFT_DRAG       | 绕地球旋转 | 地图上平移   | 地图上平移 |
| RIGHT_DRAG      | 地图缩放  | 地图缩放    | 地图缩放  |
| MIDDLE_DRAG     | 倾斜地球  | 倾斜地球    | 无     |
| WHEEL           | 地图缩放  | 地图缩放    | 地图缩放  |
| CTRL+LEFT_DRAG  | 倾斜地球  | 倾斜地球    | 无     |
| CTRL+RIGHT_DRAG | 倾斜地球  | 倾斜地球    | 无     |

**相机默认操作属性**

|   |   |
|---|---|
|lookEventTypes|3D 视图、2.5D 视图，改变相机观察方向|
|rotateEventTypes|3D 视图，相机绕地球旋转|
|tiltEventTypes|3D 视图、2.5D 视图，倾斜视角|
|translateEventTypes|2.5D 视图、2D 视图，地图上平移|
|zoomEventTypes|地图缩放|

# 场景渲染
当需要实时监听场景渲染时，以下事件必不可少（如场景渲染后回调实时更新的实体坐标等）


|   |   |
|---|---|
|Scene.preUpdate|场景更新前事件，即更新或呈现场景之前将引发的事件|
|Scene.postUpdate|场景更新后事件，即更新场景之后及渲染场景之前立即引发的事件|
|Scene.preRender|场景渲染前事件，即更新场景之后及渲染场景之前将引发的事件|
|Scene.postRender|场景渲染后事件，即渲染场景之后立即引发的事件|
```
	// 需要回调的函数
function callbackFun(event) {
  console.log("执行了回调函数");
}
// 注册更新之后执行的回调函数
viewer.scene.postUpdate.addEventListener(callbackFun);
// 注销之前注册的回调函数
viewer.scene.postUpdate.removeEventListener(callbackFun);

```

# 转化坐标行为
```
const handler = new Cesium.ScreenSpaceEventHandler(viewer.scene.canvas);
handler.setInputAction(function (event) {
  // 获取屏幕坐标
  const screen = event.position;
  console.log("屏幕坐标：", screen);
  // 获取椭球面坐标（Cartesian3：不包含地形、模型、倾斜摄影模型表面）
  const ellipsoid = viewer.scene.camera.pickEllipsoid(event.position);
  console.log("屏幕坐标转椭球面坐标：", ellipsoid);
  // 获取地表坐标（Cartesian3：包含地形，不包括模型、倾斜摄影模型表面）
  const ray = viewer.camera.getPickRay(event.position);
  const surface = viewer.scene.globe.pick(ray, viewer.scene);
  console.log("屏幕坐标转地表坐标：", surface);
  // 获取场景坐标（Cartesian3：包含地形、模型、倾斜摄影模型表面）
  const cartesian3 = viewer.scene.pickPosition(event.position);
  console.log("屏幕坐标转场景坐标：", cartesian3);
 
  // 世界坐标转屏幕坐标
  const cartesian2 = Cesium.SceneTransforms.worldToWindowCoordinates(viewer.scene, cartesian3);
  console.log("世界坐标转屏幕坐标：", cartesian2);
 
  // 世界坐标转WGS84坐标（弧度）
  const cartographic_radian = Cesium.Cartographic.fromCartesian(cartesian3);
  console.log("世界坐标转WGS84坐标（弧度）：", cartographic_radian);
 
  // 弧度转经纬度坐标
  const lon = Cesium.Math.toDegrees(cartographic_radian.longitude); // 经度
  const lat = Cesium.Math.toDegrees(cartographic_radian.latitude); // 纬度
  console.log("世界坐标转WGS84坐标（经纬度）：{Longitude：%f, Latitude: %f}", lon, lat);//有固定位置的输出
 
  // 经纬度坐标转世界坐标
  const cartesian3_new = Cesium.Cartesian3.fromDegrees(lon, lat, cartographic_radian.height);
  console.log("经纬度坐标转世界坐标：", cartesian3_new);
 
  // 弧度坐标转世界坐标
  const cartesian3_new2 = Cesium.Cartesian3.fromRadians(
    cartographic_radian.longitude,
    cartographic_radian.latitude,
    cartographic_radian.height,
  );
  console.log("弧度坐标转世界坐标：", cartesian3_new2);
}, Cesium.ScreenSpaceEventType.LEFT_CLICK);

```
