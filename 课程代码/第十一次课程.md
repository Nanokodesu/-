### 一、分类设色常见错误与调试

#### 1.1 错误一：材质设置放在异步函数之外 ⚠️

**问题现象**：分类设色代码写好了，但模型不显示颜色

**原因分析**：
- 加载白模使用的是**异步函数**（后台慢慢加载，先跑下面的代码）
- 如果把材质/颜色设置放在异步函数**外面**
- 执行顺序变成：先设色 → 后台再加载模型 → 模型都没出来怎么设色？

**解决方法**：
```
✅ 正确：将材质设置写在 .then(function(){ ... }) 异步回调内部
❌ 错误：将材质设置写在异步函数外部
```

#### 1.2 错误二：透明度设置与鼠标高亮冲突 ⚠️

**问题现象**：选择模型时鼠标移动不高亮（白模时正常高亮）

**原因分析**：
- `color` 材质设置了 **alpha 透明度**（如源代码中的 0.5）
- Cesium 的**边缘检测（edgeDetection）** 与透明度产生冲突
- 导致 `Silhouette` 高亮功能失效

**解决方法**：
```javascript
// ❌ 有问题的代码（含透明度）
material: new Cesium.ColorMaterialProperty(
    new Cesium.Color(1.0, 1.0, 1.0, 0.5)  // ← 这里的 0.5 透明度导致冲突
)

// ✅ 修复后（去掉透明度参数）
material: new Cesium.ColorMaterialProperty(
    new Cesium.Color(1.0, 1.0, 1.0)  // ← 删除第4个参数
)
```

> 删除所有建筑分类设置的透明度之后，高亮功能恢复正常。

#### 1.3 其他调试技巧

- **鼠标事件冲突**：绘图用左键 + 选择要素也用左键 → 冲突
	- 解决：建两个鼠标事件，绘图时关掉第一个，不绘图时关掉绘图的
- **对比展示恢复**：对比展示结束后要恢复高亮状态
- **代码逻辑 bug**：大部分需求实现不难，但细节逻辑容易出错

### 二、标签合并显示（名称 + 类型）⭐

#### 需求
标签既要显示**建筑名称**，又要显示**建筑类型**

**效果示例**：`主楼(行政楼)` 而非仅仅 `主楼`

#### 实现原理
本质是两个字符串变量的**拼接**，使用 ES6 **反引号模板字符串**：

```javascript
// 原来的代码——只显示名称
div.textContent = rightName;

// 修改后——名称 + 类型
div.textContent = `${rightName}(${rightType})`;
```

> 反引号 `` ` `` 内使用 `${}` 引用变量，实现字符串插值。

### 三、GLSL 着色器语言基础原理 ⭐⭐

#### 3.1 为什么需要 GLSL？
前面的课程中给建筑模型设计颜色，最复杂的方式就是直接赋一个纯色值。但如果想要更酷炫的效果（如渐变色、动态光效），就需要通过 **GPU 渲染** 来获得更大的图形控制能力。这就是 GLSL（OpenGL Shading Language）的用武之地。

#### 3.2 两大核心着色器

GLSL 有两大主要着色器，协作完成渲染：

| 着色器 | 英文名 | 功能 |
|--------|--------|------|
| **顶点着色器** | Vertex Shader | 处理**顶点**属性，为每个顶点设置颜色通道 |
| **片元着色器** / 光栅着色器 | Fragment Shader | 将三角形区域光栅化为像素格子，对区域内部进行颜色**插值** |

> **Cesium 自定义着色器接口**：`Cesium.CustomShader`
> - 获取属性：`FragmentInput`（即 `fsInput`）
> - 修改材质：`czm_material`（即 `material`）

#### 3.3 渲染基本流程 ⭐⭐⭐

```
步骤一：三个顶点 A、B、C 各自拥有位置坐标和颜色通道（RGB）
        ↓
步骤二：片元着色器将三角形区域"光栅化"为一堆像素格子
        （像素越小 → 分辨率越高 → 插值越精细）
        ↓
步骤三：在区域内进行颜色插值（Interpolation）
        - A点红色 → B点绿色 → AB连线上红绿渐变
        - 任意一点 P 的颜色 = 由三顶点共同决定
        ↓
步骤四：输出最终颜色 → 屏幕显示
```

**核心概念 —— 插值（Interpolation）**：

假设三角形 ABC 三个顶点的颜色分别为：
- A = 红色 (R)
- B = 绿色 (G)
- C = 蓝色 (B)

则三角形内部**任意一点 P** 的颜色由三点插值决定：
- P 的 RGB 值都是 **0~1** 之间的浮点数
- 每个通道的值根据 P 到各顶点的距离权重计算

> 这就是 Photoshop 渲染的基本原理！像素密度越高，色彩过渡越平滑。

#### 3.4 GLSL 基本数据类型

| 类型 | 含义 | 常见用途 |
|------|------|----------|
| **vec3** | 三维向量 | XYZ 坐标 / RGB 颜色通道 |
| **vec4** | 四维向量 | RGBA 颜色（RGB + Alpha透明度） |
| **float** | 浮点数 | 精度数值（如 0.5、1.23） |
| **int** | 整数 | 整型数值（和C语言一致） |

> **vec3 vs vec4 的区别**：
> - `vec3` 用于三维位置（XYZ）或 RGB 颜色
> - `vec4` = RGB + Alpha（透明度），用于需要控制不透明度的场景
> - 颜色的深浅程度用 **Alpha（阿尔法）** 通道来表示

#### 3.5 核心数学函数速查

| 函数 | 功能 | 本课应用 |
|------|------|----------|
| `clamp(value, min, max)` | 数值限制在 [min, max] 范围内 | 将任意高度标准化到 0~1 |
| `fract(x)` | 提取小数部分 `x - floor(x)` | 时间→0~1 循环 |
| `abs(x)` | 绝对值 | 线性变往复变换 |
| `step(edge, x)` | 阶梯函数（x≥edge→1, 否则→0） | 高亮范围分段判断 |

#### 3.6 简单实例：高度映射颜色的渐变效果

```glsl
// 顶点着色器（Vertex Shader）—— 设置每个顶点的属性
// 通过 position（位置坐标）来计算颜色
// position.z 代表高度 → 用高度来映射 RGB 通道

// 片元着色器（Fragment Shader）—— 对区域进行颜色插值
// 输入参数：
//   fsInput    → 包含顶点的属性信息（从顶点着色器传来）
//   material   → 包含整个材质的属性

// 核心逻辑（简化版）：
vec3 positionMC = fsInput.positionMC;  // 获取当前顶点的三维坐标
// positionMC.z 就是建筑的高度值

// 用高度来控制颜色通道
float greenChannel = clamp(1.0 - positionZ * 0.05, 0.0, 1.0);
float blueChannel  = clamp(1.0 - positionZ * 0.001, 0.0, 1.0);

material.color = vec3(0.0, greenChannel, blueChannel);  // RGB输出
```

**颜色效果**：
- **低层建筑**（z ≈ 0）：green→1, blue→1 → **蓝绿混合色调**
- **高层建筑**（z 很大）：green→≈0, blue→较高 → **偏蓝色调**

> 🔧 可以修改 RGB 通道系数来调整颜色效果，比如把绿色通道调低、蓝色调高会产生颜色翻转。

### 四、渐变动态特效（Gradient Effects）⭐⭐⭐

本节包含两个函数：**渐变色** 和 **动态光环**，通过 `case` 选择切换。

#### 4.1 渐变色函数 —— 核心原理

**目标**：让建筑从底层到顶层呈现渐变色彩（而非单一颜色）

##### 关键参数理解

```
fsInput   → 顶点属性（position 坐标等来自每个顶点）
material  → 材质属性（整体材质的统一属性）
```

获取建筑高度：
```glsl
vec3 positionMC = fsInput.positionMC;  // 三维坐标 (X, Y, Z)
// positionMC.z = 建筑高度 ✅ 就是用 Z 轴来映射颜色
```

##### clamp() —— 数值标准化 ⭐

`clamp(value, min, max)` 将任意数值限制在指定范围内：

```glsl
// 无论输入值多大或多小，输出一定是 min ~ max 之间
clamp(任意值, 0.0, 1.0)  → 结果一定在 [0, 1] 区间内
```

> 课程中反复强调的设计原则：**所有数据运算都基于 0~1 的范围**

##### 颜色通道计算逻辑详解 ⭐⭐⭐

```glsl
// 红色通道：固定为 0
float red   = 0.0;

// 绿色通道：随高度增加而减小（系数大 → 变化快）
float green = clamp(1.0 - positionMC.z * 0.05, 0.0, 1.0);

// 蓝色通道：随高度增加而减小（系数小 → 变化慢）
float blue  = clamp(1.0 - positionMC.z * 0.001, 0.0, 1.0);

material.color = vec3(red, green, blue);
```

**数学推导**：

| 建筑高度 | z 值趋势 | green = 1 - z×0.05 | blue = 1 - z×0.001 | 最终颜色 |
|----------|---------|---------------------|---------------------|----------|
| 低层（近地面） | ≈ 0 | ≈ **1.0** | ≈ **1.0** | 🟦 蓝绿混合 |
| 中层 | 中等 | 中等值 | 接近 1.0 | 青蓝色 |
| 高层 | 很大 | ≈ **0.0** | 较高值 | 🔵 **偏蓝色** |

**关键洞察**：绿色通道系数（0.05）>> 蓝色通道系数（0.001）
→ 高层时绿色先趋于零，蓝色仍保持较高值
→ **顶端越来越偏蓝**

#### 4.2 动态光环函数（Dynamic Glow/Halo Effect）⭐⭐⭐

**效果**：建筑上有一个上下往复移动的高亮光环带（智慧城市展示中常用酷炫特效）

##### 4.2.1 实现原理

> **不是**创建一个新的光环物体往上移！
> **而是**实时改变建筑表面某一高度位置的颜色（提高亮度/曝光）

##### 4.2.2 第一步：时间 → 位置转换

网页以 **60帧/秒** 刷新。利用帧率将时间转换为位置：

```glsl
// 将时间转化为 0~1 范围的位置参数
float rawPosition = timeRelatedValue;
```

##### 4.2.3 第二步：fract() 提取小数位 ⭐⭐

**问题**：时间是持续累加的（一直变大），需要把它限制在 0~1 循环

**解决方案**：`fract(x)` 提取小数部分

```
fract(x) = x - floor(x)
```

其中 `floor(x)` = 向下取整（≤ x 的最大整数）

**计算示例**：
| 输入 x | floor(x) | fract(x) = x - floor(x) |
|--------|----------|--------------------------|
| 2.2 | 2 | **0.2** ✅ 小数位 |
| 5.78 | 5 | **0.78** |
| -0.2 | **-1**（比-0.2小的整数） | **0.8** ⚠️ 注意！负数的 fract 不是简单的小数位 |

> 大于零的数 → fract 直接等于小数位；负数需要特别注意计算规则。

**结果**：无论原始值多大，fract() 后得到的一定是 **[0, 1)** 的循环值

##### 4.2.4 第三步：线性变往复 —— abs() 变换 ⭐⭐⭐

**问题**：fract 得到的是 **0→1 线性递增**（到1后归零重新开始），但我们需要的是**上下往复**运动

**数学变换**：

```
原始：y = x （线性 0→1，然后跳回0）
目标：y = 往返运动（0→1→0→1...）
```

**推导过程**（以 0.5 为分界线）：

```
当 x ∈ [0, 0.5] 时：希望 y 从 1→0
  → y = -2x + 1  （斜率为-2，截距为1）
  → 提取公因式：y = 2 × (0.5 - x)

当 x ∈ [0.5, 1] 时：希望 y 从 0→1
  → y = 2x - 1   （斜率为2，向右平移0.5）
  → 即：y = 2 × (x - 0.5)

两段合并（利用绝对值合并分段函数）：
  → y = 2 × |0.5 - x|
  → y = abs(2 × (0.5 - x))
  → y = abs(1 - 2x)
```

**图示理解**：

```
y
↑
1 |╲     ╱
  │ ╲   ╱
  │  ╲ ╱
  │   ╲    ← 在 x=0.5 处取得最小值 0
0 +———┼———→ x
  0  0.5  1
```

**一行代码搞定往复变换**：

```glsl
float pPrime = abs(2.0 * (0.5 - rawPosition));  // 0→1→0 往复变化
```

##### 4.2.5 第四步：阈值判断确定高亮范围 ⭐⭐

**思路**：光环不是一条线，而是一个**带状区域**（有厚度）

- 当前扫过的位置：`pPrime`（一个 0~1 的值）
- 建筑上每个高度都有一个对应的标准化值：`h`
- 判断：如果 `|pPrime - h| < 阈值` → 该位置高亮

```glsl
// 阈值设定：往上 1%（0.01）+ 往下 1%（0.01）
// 即高亮区域的厚度 = 0.02（占总高度的2%）
float threshold = 0.01;

// 计算当前位置与建筑高度的差值
float diff = abs(pPrime - normalizedHeight);

// 差值 < 阈值 → 在光环范围内 → 高亮
// 差值 ≥ 阈值 → 不在范围内 → 不变色
```

##### 4.2.6 第五步：step() 函数实现分段 ⭐

`step(edge, x)` 是 GLSL 的阶梯/分段函数：

```
step(threshold, diff) 的行为：
  当 diff < threshold 时 → 返回 0
  当 diff ≥ threshold 时 → 返回 1
```

但我们需要的逻辑是**反过来的**（小于阈值时=高亮=1）：

```glsl
// step 的默认行为：step(edge, x): x<edge→0, x≥edge→1
// 所以 step(0.01, diff): diff<0.01→0, diff≥0.01→1

// 反转逻辑：用 1 减去它
highlight = 1.0 - step(0.01, diff);
// 现在：diff<0.01→1（高亮✅），diff≥0.01→0（不变✅）
```

##### 4.2.7 最终应用：颜色翻倍实现高亮

```glsl
// 在基础渐变色的基础上，高亮区域颜色翻倍
if (highlight > 0.5) {
    material.color *= 2.0;  // RGB各通道乘以2 → 变亮/曝光增强
}
```

##### 4.2.8 高度范围限制

光环不是从建筑底部开始，可以设置最低和最高高度：

```glsl
// 只对 18m ~ 90m 高度的建筑显示光环
float adjustedHeight = positionMC.z - minHeight;  // 减去最低高度(18m)
float maxHeightRange = 90.0 - 18.0;               // 最大范围72m
float normalizedHeight = adjustedHeight / maxHeightRange;  // 归一化到0~1
```

> 超过 90m 的建筑顶部会出现一段**无光环空档区**

##### 4.2.9 动态光环完整流程总结

```
① 获取系统时间 → 转换为位置参数
② fract() 提取小数位 → 得到 0~1 循环值
③ abs(2×(0.5-x)) 往复变换 → 0→1→0 往复运动
④ 将建筑高度归一化到限定范围（如 18m~90m）
⑤ 计算光环位置与当前高度的差值
⑥ step() + 1减反转 → 得到高亮掩码（0或1）
⑦ 高亮区域颜色通道翻倍 → 视觉上的光环效果
⑧ 每秒60帧刷新 → 连续动画
```

### 五、雷达扫描（Radar Scan）—— CallbackProperty 替代方案 ⭐⭐

#### 5.1 设计思想：GLSL 不是唯一解

雷达扫描是消防预警、安防系统中非常常用的可视化效果。虽然可以用 GLSL 实现，但：
- GLSL 实现约需 **200行代码**
- 纯数学运算，逻辑复杂
- 有更简单的替代方案

#### 5.2 CallbackProperty 方案 ⭐

**核心思路**：
- 雷达扫描的本质是一个**旋转的扇形材质**
- 扇形本身不变，只是**角度在随时间变化**
- 使用 `CallbackProperty` **实时回调**旋转角度即可
- 每秒刷新角度 → 材质贴在不同位置 → 实现扫描动画

**优势**：
- 代码量极少（十几行）
- 逻辑清晰，易于理解和修改
- 性能良好（只需更新一个角度参数）

#### 5.3 实现要点

```javascript
// 使用 CallbackProperty 动态更新旋转角度
const scanAngle = new Cesium.CallbackProperty(function(time) {
    // 根据时间计算当前旋转角度
    return (time.secondsOfDay * speed) % Cesium.Math.TWO_PI;
}, false);

// 创建扇形实体，绑定旋转角度
viewer.entities.add({
    position: centerPosition,
    ellipse: {
        semiMinorAxis: radius,
        semiMajorAxis: radius,
        rotation: scanAngle,          // ← 动态旋转角度
        material: radarMaterial,      // 雷达扫描材质（从texture文件夹加载）
        outline: true,
        outlineColor: Cesium.Color.RED  // 边框颜色
    }
});
```

#### 5.4 材质与颜色分离设置 ⭐

雷达扫描的**扇形填充色**和**边框颜色**可以**分开设置**：

| 属性 | 参数 | 说明 |
|------|------|------|
| 扇形填充 | `material` | 扫描区域的材质/颜色 |
| 边框颜色 | `outlineColor` | 扇形边缘线条颜色 |
| 边框宽度 | `outlineWidth` | 边框粗细 |

> 例：扇形用黄色半透明材质 + 边框用红色 → 两种颜色独立控制
> 修改扇形颜色改 `material`，修改边框颜色改 `outlineColor`

#### 5.5 材质来源

雷达扫描使用的材质图片存放在项目的 **`Data/Texture/`** 文件夹中。后续课程中的下雨、下雪等天气效果也会调用此文件夹中的材质。
