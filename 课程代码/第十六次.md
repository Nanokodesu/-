#nano 
- HTML语言（决定网页包括什么）：超文本标记语言（HyperText Markup Language），定义网页结构和内容的标记语言。用<>内的不同标签控制了网页不同元素的开始与结束
    

```HTML
<script type="text/javascript" src="./Build/Cesium/Cesium.js"></script>
```

- CSS语言（设计网页什么样子）：层叠样式表（Cascading Style Sheets），控制HTML 元素外观的样式表语言。比如，元素的布局、颜色、字体、位置、边距等。
    

```CSS
@font-face {
  font-family: "TitleFont";
  src: url("Font/DingTalk JinBuTi.ttf") format("truetype");
}
 
.navbar .logo {
  float: left;
  color: #ffffff;
  text-align: center;
  padding: 0px 20px;
  text-decoration: none;
  text-shadow: #000000 2px 2px 0px;
  font-size: 24px;
  font-family: "TitleFont", sans-serif;
}
```

- 与上述 CSS 样式相对应的 HTML 元素为：
    

```HTML
<div class="navbar">
  <div class="logo">
    <p style="font-weight: bold;">智慧校园 BJFU</p>
  </div>
</div>
```

## 2.1 标题

- 通过<h1>至<h6>标签进行定义的。<h1>定义最大的标题。<h6>定义最小的标题。

## 2.2 段落
```
- 通过<p>标签进行定义的。浏览器会自动地在段落的前后添加空行。
    
- 通过<br>进行段落之间的换行
    
```

```HTML
<!-- 标题与段落 --><h3>INTRODUCTION</h3><p>    北京林业大学是教育部直属，教育部、国家林业和草原局、    北京市人民政府共建的全国重点大学，是国家首批“211工程”重点建设高校和国家“优势学科创新平台”建设项目试点高校，是国家“双一流”建设高校。    <br>学校现有17个学院，有65个本科专业（含专业方向），1个双学士学位、22个辅修学士学位。    <br>学校以生物学、生态学为基础，以林学、风景园林学、林业工程、水土保持与荒漠化防治、草学和农林经济管理为特色，是农、理、工、管、经、文、法、哲、教、艺等多门类协调发展的全国重点大学。</p>
```

## 2.3 图像

- 通过<img>标签定义一个空标签，使用 src 源属性提供图像的 URL 地址
    
- 通过 height、width 高度和宽度属性定义图像的高度与宽度
    

```HTML
<!-- 图像 --><h3>IMAGES</h3><img src="./Texture/Radar.png" width="500" height="200" />
```

## 2.4 列表

- 无序列表：使用圆点进行标记，通过<ul>和<li>标签创建无序列表、定义列表内容
    
- 有序列表：使用数字进行标记，通过<ol>和<li>标签创建有序列表、定义列表内容
    

```HTML
<!-- 无序列表 --><h3>LIST-SERVICE</h3><ul>    <li>学校主页</li>    <li>教师查询</li>    <li>成绩查询</li></ul> <!-- 有序列表 --><h3>LIST-CLASS</h3><ol>    <li>城规23-1</li>    <li>城规23-2</li></ol>
```

2.5 链接

- 通过<a>标签定义一个超链接，使用 href 属性提供目标 URL
    
- 通过设置 href="#" 导航到页面顶部
    
- 可以设置如 download、title、target 等属性
    

```HTML
<!-- 链接 --><h3>LINK</h3><a href="https://www.bjfu.edu.cn/" download title="点击访问北京林业大学主页" target="_blank">北京林业大学主页</a>
```

## 2.6 表单

- 通过<input>标签创建文本输入框，使用 type 类型属性定义输入框的类型，例如 checkbox 复选框、text 文本输入框、radio 单选按钮等，onclick 设置调用函数
    
- 通过<select>标签创建下拉列表，使用<option>定义下拉列表中的选项
    
- 通过<button>标签定义按钮类型
    

```HTML
<!-- 表单 --><h3>FORM</h3><form>  <!-- 文本输入框 -->  <label for="username">姓名：</label>  <input type="text" name="username" /><br><br>   <!-- 复选框 -->  <label for="hobby">爱好：</label>  <input type="checkbox" name="hobby" value="reading" />阅读  <input type="checkbox" name="hobby" value="sports" />运动  <input type="checkbox" name="hobby" value="music" />音乐<br><br>   <!-- 单选按钮 -->  <label for="gender">性别：</label>  <input type="radio" name="gender" value="male" />男  <input type="radio" name="gender" value="female" />女<br><br>   <!-- 下拉列表 -->  <label for="city">城市：</label>  <select name="city">    <option value="beijing">北京</option>    <option value="shanghai">上海</option>    <option value="guangzhou">广州</option>  </select><br><br>   <!-- 按钮，点击时调用函数 -->  <button type="button" onclick　="alert('表单已提交！')">提交表单</button></form>
```

3.4 伪类

当某一个选择器处于不同状态时，为其添加不同的样式，状态由用户自主决定（不会创建新的元素，只是改变了现有元素在特定时刻的样式）。例如，鼠标点击前和鼠标点击后设置成不同的样式

伪类通过 ":" 实现，不同状态包括 link、visited、hover、active、first-child、first-letter 等

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>CSS-pseudo-class</title>
    <style>
        a:link {
            color: #1d3557;
        }
        a:visited {
            color: #6d6875;
        }
        a:hover {
            color: #e63946;
            text-decoration: underline;
        }
        a:active {
            color: #fbbf24;
        }
        ul li:first-child {
            background: #a3e635;
        }
        p:first-letter {
            font-size: 2em;
            color: #457b9d;
        }
    </style>
</head>
<body>
    <h2>伪类选择器</h2>
    <a href="https://www.bjfu.edu.cn/" target="_blank">示例链接</a>
    <ul>
        <li>第一个列表项（first-child）</li>
        <li>第二个列表项</li>
        <li>第三个列表项</li>
    </ul>
    <p>首字母会变大并变色。</p>
</body>
</html>
3.5 伪元素
创建一个不在文档树中的元素，并为其添加样式，例如在被选元素之前或者之后添加内容

伪元素通过 "::" 实现，例如 ::before、::after

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>CSS-pseudo-element</title>
    <style>
        .before-after-demo::before {
            content: "★ ";
            color: #fbbf24;
        }
        .before-after-demo::after {
            content: " ◀";
            color: #219ebc;
        }
        .first-line-demo::first-line {
            color: #e63946;
            font-weight: bold;
        }
    </style>
</head>
<body>
    <h2>伪元素选择器</h2>
    <div class="before-after-demo">这是一个带有 ::before 和 ::after 的元素</div>
    <p class="first-line-demo">这是一段演示 ::first-line 伪元素效果的文本。你会发现本段文字的第一行会变成红色并加粗。</p>
</body>
</html>
