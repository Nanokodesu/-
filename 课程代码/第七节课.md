定义了名字

变量声明
- **类型**
- const
	- 作用域是最小的
	- 既不能重复声明也不能重复赋值
	- 函数里重复声明也可以
- let
	- 块级作用域（没有块就是一个块），必须在块级作用域里有效
	- 不允许重复声明
	- 可以重复赋值
- var
	- 作用域范围是最大的
	- 声明全局变量
	- 重复声明，但不赋值是无效的
	- 重复声明按最后为准

暂存死区
- 只声明，没有告诉值
- ***必然会报错***
- 但是可以新建变量来进行
先输出、再声明 肯定报错
**函数提升**
- **js的运行分两步运行**  
- 函数提升
- 上下文

```
function varExample() {
  var output = 1;                  // 声明在函数块内
  console.log(output);           
}
 
varExample()                       // 输出: 1
console.log(output);               // 报错
```

```
	var output = 1;                    // 声明全局变量
function varExample() {
  console.log(output);            
}
 
varExample()                       // 输出: 1
console.log(output);               // 输出: 1
```



# 画点线面模型等等
静态绘制
- 点、模型
- 左键获取坐标，在坐标的位置上添加一个点

动态绘制
- **线面圆矩形**的绘制
- 需要起点、需要有暂时静态的状态
- 需要实时动态画动
	- 通过移动来获取 mouse_move
