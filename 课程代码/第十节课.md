### 一、沿路注数（在道路两侧种树）

#### 1. 核心思路
- **简化问题**：不在道路两侧直接种树，而是先从**道路中心线**出发种树，再往两侧偏移
- **输入数据**：
	- 树的模型文件（`.glb` / `.gltf` 格式，从 Blender 导出）
	- 道路中心线的矢量数据（GeoJSON 格式）

#### 2. 第一步：在道路中心线上定位点位 —— 线性插值（Lerp）

**基本原理**：
- 已知起点 O 和终点 A 的坐标，在线段 OA 上任取一点 P
- P 点坐标 = OP 占 OA 的**比值** × A 点坐标
- 本质：利用**相似三角形**

> 例：若 P 点距离起点占总长度的 50%，则 P 点 X 坐标 = A 点 X 坐标的 50%，Y 坐标同理

**折线道路处理方法**：

将折线拆成多段直线段 → 计算每段端点距起点的**累计距离**→ 判断目标点落在哪一段 → 在该段内做线性插值

```
例：三段路，各段长度为 10m
- 端点累计距离：0 → 10 → 20 → 30
- 若要种的树距起点 5m → 落在第1段(0~10)内 → 比值=5/10=50%
- 若要种的树距起点 15m → 落在第2段(10~20)内 → 段内偏移=15-10=5m → 比值=5/10=50%
```

> API：使用 Cesium 的 `Cartesian3.lerp()` 方法实现线性插值

#### 3. 第二步：向两侧偏移 —— 向量叉乘（Cross Product）

##### 3.1 向量叉乘的几何意义
- 对于向量 **a** 和 **b**，叉乘结果是一个新向量，**同时垂直于 a 和 b**（绝对正交）
- **点乘** vs **叉乘**：
	- **点乘**：|a| × |b| × cos(α) → 结果是标量（数值）
	- **叉乘**：结果是与两向量都垂直的**方向向量**

##### 3.2 用叉乘确定左右方向
已知两个方向向量：
1. **前进方向**：沿着道路中心线前进的方向
2. **向上方向**：地表法线（垂直于地表向上）

→ 叉乘结果就是**垂直于道路方向的横向向量**（要么向左，要么向右）

##### 3.3 右手法则判断方向 ⭐
```
操作步骤：
1. 伸出右手
2. 四指指向你要种树的方向（前进方向）
3. 弯曲四指指向地表向上的方向
4. 大拇指指向的方向 = 正向（右侧）偏移方向
```
- **正向叉乘** → 得到右侧方向
- **加负号** → 反转为左侧方向

##### 3.4 方向 + 距离 = 最终偏移量
- 方向向量是单位向量时（模长=1）：
	- 偏移量 = 方向(+1/-1) × 距离(如5m)
- 如果方向向量不是单位向量：
	- 例：向量=(3,4)，模长=5 → 想要偏移5m，实际会偏移25m！

##### 3.5 向量标准化（Normalization）⭐
- 将任意向量转换为**模长=1**的单位向量
- 例：(3, 4) → 标准化后 = (3/5, 4/5) = (0.6, 0.8)
- 利用**相似三角形**原理：保持方向不变，缩放至单位长度
- **必须先标准化再乘以偏移距离！**

#### 4. 第三步：随机朝向 —— 避免所有树方向一致
- 每棵树生成一个 **0 ~ 360° 的随机角度**
- 使用 `HeadingPitchRoll` 设置树的朝向
- 目的：让所有树的生长方向看起来不一样，更自然

#### 5. 完整算法流程总结
```
① 加载道路中心线 GeoJSON 数据
② 提取所有折点坐标，计算累计距离数组
③ 沿中心线每隔固定间距（如15m），用 lerp 插值计算点位
④ 对每个点位：
   a. 计算前进方向向量（p2 - p1）
   b. 获取地表法线（up方向）
   c. 叉乘(forward, up)得到右侧方向
   d. 标准化方向向量
   e. 方向 × 偏移距离 = 左右偏移量
   f. 原始坐标 + 偏移量 = 最终种植位置
   g. 随机生成朝向角度
⑤ 加载树木模型(.glb)，添加到场景中
```

### 二、全景地图（Panorama Map）

#### 1. 基本概念
- 全景地图本质上不是依赖 Cesium 地图框架
- 它是将三维视角**切换为非三维的空间展现方式**
- 依赖**全景照片**（2:1 宽高比的等距柱状投影图片）

#### 2. 核心问题：缩放机制不同 ⭐⭐
- **Cesium 三维模式下的缩放**：移动**镜头**（camera）的位置
	- 往前推滚轮 → 镜头往前走（物体变大）
	- 往后推滚轮 → 镜头往后退（物体变小）
	- 以**地心**为中心进行镜头移动
- **全景模式下的缩放**：不能移动镜头，改用**变焦（FOV变化）**
	- 镜头固定不动
	- 通过改变**视场角（Field of View）** 来实现放大/缩小
	- FOV 变小 → 放大效果；FOV 变大 → 缩小效果
	- 类似相机换镜头（长焦/广角）

#### 3. 视场角参数设置
```javascript
最小 FOV: 20° （最大放大）
最大 FOV: 100° （最大缩小）
变焦速度: 0.05
```

#### 4. 关键代码逻辑
- 进入全景模式：
	- 隐藏地球（`globe.show = false`）
	- 创建 `EquirectangularPanorama` 全景球体
	- 镜头瞬间移动到球体中心
	- **禁用默认滚轮缩放**（`enableZoom = false`）
	- 自定义滚轮事件：改变 `frustum.fov` 实现变焦
	- 显示退出按钮
- 退出全景模式：
	- 恢复地球显示
	- 移除全景球体
	- 解除镜头锁定
	- 恢复默认 FOV（60°）
	- 镜头飞回原位

### 三、面内种植（在多边形区域内种草/花）

#### 1. 与线种植的区别
- **线种植**：几十个模型（树木），数量少
- **面种植**：几千甚至几万个模型（草/花卉），数量大
- **算法不同**：核心难点是如何判断一个点是否在多边形内部

#### 2. 射线法（Ray Casting Algorithm）⭐⭐⭐

##### 2.1 基本思想
对多边形内的任意待测点 P，做一条**向右的平行射线**（平行于X轴），统计该射线与多边形边界的**交点个数**：
- **奇数个交点** → P 点在多边形**内部**
- **偶数个交点** → P 点在多边形**外部**

> 直觉理解：每次穿过边界就切换一次"内/外"状态

##### 2.2 交点的 X 坐标计算
已知：P 点坐标(px, py)，边两端点(xi, yi)和(xj, yj)

射线与边的交点 Y 坐标 = py（因为射线平行于X轴）
交点 X 坐标通过**相似三角形**推导：

```
X = xi + (xj - xi) × (py - yi) / (yj - yi)
```

判断条件：px < X → 交点在P点右侧（有效交点）；否则忽略

##### 2.3 端点处理的陷阱 ⚠️
- 当射线刚好经过某条边的**端点**时，该端点会被**两条边各计一次**→ 导致误判
- 解决方案：采用**半开半闭区间**
	- 一侧用 `>=`，另一侧用 `>`
	- 保证每个端点只被计算一次
	- 如：`(yi > y) !== (yj > y)` — 一边严格大于，另一边大于等于

##### 2.4 包围盒优化（Bounding Box）
- 问题：如果多边形很小，在整个空间中随机取点效率极低
- 解决方案：先画一个**最小的包围盒（矩形）**
	- 计算多边形的最小/最大经纬度
	- 只在包围盒范围内随机生成点
	- 再用射线法判断是否真正在多边形内
- 大幅减少无效采样次数

##### 2.5 完整算法流程
```
① 加载多边形 GeoJSON 数据，提取所有顶点坐标
② 计算包围盒（minLon, maxLon, minLat, maxLat）
③ 循环直到达到目标数量：
   a. 在包围盒内随机生成一个点
   b. 用射线法判断该点是否在多边形内
   c. 若不在 → 跳过，重新生成
   d. 若在 → 种植模型，计数+1
④ 安全计数器：防止无限循环（上限 = 目标数×10）
```

### 四、Entity vs Primitive（两种加载模型的方案对比）⭐

| 特征 | **Entity** | **Primitive** |
|------|-----------|--------------|
| **底层基础** | 以**空间实体**为核心 | 以**图形渲染**为核心 |
| **渲染方式** | 每个实体发送一次渲染指令 | **一次指令渲染全部模型** |
| **实例化渲染** | 不支持 | 支持 |
| **功能丰富度** | 高（保留所有属性和交互信息） | 低（纯几何渲染） |
| **适用规模** | 少量实体（建筑、单个设施） | 大批量展示（草地、森林） |

#### 选择建议
- **Entity 方案**（方案一）：适用于需要获取单个实体的属性、功能信息的情况<br>
	如建筑模型需要切片交互、查询属性
	- 缺点：5000 个草 = 发送 5000 次渲染指令 → CPU 占用率高 → 卡顿
- **Primitive 方案**（方案二）：适用于大规模展示场景<br>
	先将所有模型合并，只告诉 Cesium 一次"画出这5000个"
	- 优点：性能好，可支持上万个模型
	- 缺点：单个实体无独立属性
- **超大规模**（几十万级）：需在前端（如 Three.js / Render）中做好**实例化**后再加载

```
function plantTreesAlongRoute(viewer, jsonUrl, modelUrl) {

    Cesium.GeoJsonDataSource.load(jsonUrl).then(function (dataSource) {

        const entities = dataSource.entities.values;
        let roadPositions = [];

        // 提取路线中所有折点的坐标
        for (let i = 0; i < entities.length; i++) {
            const entity = entities[i];
            if (entity.polyline) {
                roadPositions = entity.polyline.positions.getValue(Cesium.JulianDate.now());
                break;
            }
        }

        if (roadPositions.length < 2) {
            console.warn("未找到有效路线！");
            return;
        }

        const treeSpacing = 15.0;              // 树木间距：15米
        const offsetDistance = 2.0;            // 向道路左右偏移 2 米

        // 将折线转变为直线段，并计算每个折点之间的距离，得到一个累积距离数组
        const distances = [0];
        let totalDistance = 0;
        for (let i = 0; i < roadPositions.length - 1; i++) {
            const dist = Cesium.Cartesian3.distance(roadPositions[i], roadPositions[i + 1]);
            totalDistance += dist;
            distances.push(totalDistance);
        }

        let currentTreeDist = 0;

        // 开启深度测试，保证贴地效果
        viewer.scene.globe.depthTestAgainstTerrain = true;

        // 沿路计算种树位置
        while (currentTreeDist <= totalDistance) {

            // 寻找某点所在的路段
            let segmentIndex = 0;
            for (let i = 0; i < distances.length - 1; i++) {
                if (currentTreeDist >= distances[i] && currentTreeDist <= distances[i + 1]) {
                    segmentIndex = i;
                    break;
                }
            }

            const p1 = roadPositions[segmentIndex];
            const p2 = roadPositions[segmentIndex + 1];

            const segmentLength = distances[segmentIndex + 1] - distances[segmentIndex];
            const distInSegment = currentTreeDist - distances[segmentIndex];
            const fraction = segmentLength === 0 ? 0 : distInSegment / segmentLength;

            // 当前树木的中心位置
            const centerPosition = Cesium.Cartesian3.lerp(p1, p2, fraction, new Cesium.Cartesian3());

            // 种树前进方向
            const forward = new Cesium.Cartesian3();
            Cesium.Cartesian3.subtract(p2, p1, forward);
            Cesium.Cartesian3.normalize(forward, forward);

            // 地表法线（垂直于地表）
            const up = viewer.scene.globe.ellipsoid.geodeticSurfaceNormal(centerPosition);

            // 叉乘算出右侧方向（左右移动方向）
            const right = new Cesium.Cartesian3();
            Cesium.Cartesian3.cross(forward, up, right);
            Cesium.Cartesian3.normalize(right, right);

            // 定义一个函数来添加树实体
            const addTreeEntity = (basePosition) => {
                const heading = Math.random() * Cesium.Math.TWO_PI;
                const hpr = new Cesium.HeadingPitchRoll(heading, 0, 0);
                const orientation = Cesium.Transforms.headingPitchRollQuaternion(basePosition, hpr);

                viewer.entities.add({
                    position: basePosition,
                    orientation: orientation,
                    model: {
                        uri: modelUrl,
                        scale: 1 + Math.random() * 0.5,
                        heightReference: Cesium.HeightReference.CLAMP_TO_GROUND,
                        // 大批量模型关闭阴影计算
                        castShadows: false,
                        receiveShadows: false
                    }
                });
            };

            // 向右偏移种树
            const rightOffset = new Cesium.Cartesian3();
            Cesium.Cartesian3.multiplyByScalar(right, offsetDistance, rightOffset);
            const rightTreePos = new Cesium.Cartesian3();
            Cesium.Cartesian3.add(centerPosition, rightOffset, rightTreePos);
            addTreeEntity(rightTreePos);

            // 向左偏移种树
            const leftOffset = new Cesium.Cartesian3();
            Cesium.Cartesian3.multiplyByScalar(right, -offsetDistance, leftOffset);
            const leftTreePos = new Cesium.Cartesian3();
            Cesium.Cartesian3.add(centerPosition, leftOffset, leftTreePos);
            addTreeEntity(leftTreePos);

            // 前进到下一棵树的位置
            currentTreeDist += treeSpacing;
        }

        viewer.zoomTo(viewer.entities);

    }).catch(function (error) {
        console.error("数据加载失败:", error);
    });
}
```

```JavaScript
 // 放置一个全景进入点
const panoLon = 116.342261;
const panoLat = 40.000103;
const panoPosition = Cesium.Cartesian3.fromDegrees(panoLon, panoLat, 70);

viewer.camera.flyTo({
    destination: Cesium.Cartesian3.fromDegrees(panoLon, panoLat, 5000)
});

const panoMarker = viewer.entities.add({
    position: panoPosition,
    point: {
        pixelSize: 20,
        color: Cesium.Color.YELLOW,
        outlineColor: Cesium.Color.WHITE,
        outlineWidth: 2
    },
    label: {
        text: '点击进入全景',
        font: '14px sans-serif',
        pixelOffset: new Cesium.Cartesian2(0, -30),
        fillColor: Cesium.Color.WHITE
    }
});

let panoramaPrimitive;           // 存储全景球体对象
let fovHandler;                  // 存储自定义的缩放事件监听器

// 定义函数：进入全景
function enterPanorama() {
    // 隐藏地球
    viewer.scene.globe.show = false;

    // 隐藏进入点和标签
    panoMarker.show = false;

    // 创建全景球体
    const transform = Cesium.Transforms.eastNorthUpToFixedFrame(panoPosition);
    panoramaPrimitive = new Cesium.EquirectangularPanorama({
        transform: transform,
        image: "./Data/Panorama/SchoolF14.jpg",
    });
    viewer.scene.primitives.add(panoramaPrimitive);

    // 镜头瞬间移动到全景球中心
    viewer.scene.camera.lookAt(panoPosition, new Cesium.HeadingPitchRange(0, 0, 2));

    const controller = viewer.scene.screenSpaceCameraController;

    // 允许原地旋转，但需要禁止滚轮前进
    controller.enableRotate = true;
    controller.enableCollisionDetection = false;
    controller.enableZoom = false;
    controller.enableTranslate = false;

    // 滚轮设置，采用变焦效果
    fovHandler = new Cesium.ScreenSpaceEventHandler(viewer.scene.canvas);
    fovHandler.setInputAction(function (movement) {
        const camera = viewer.camera;
        const frustum = camera.frustum;
        let fov = frustum.fov;
        const delta = movement; // 滚轮方向

        // 设置变焦参数
        const minFov = Cesium.Math.toRadians(20.0);
        const maxFov = Cesium.Math.toRadians(100.0);
        const zoomSpeed = 0.05;

        if (delta < 0) {
            fov *= 1.0 + zoomSpeed; // 缩小画面 (拉远)
        } else {
            fov *= 1.0 - zoomSpeed; // 放大画面 (拉近)
        }

        // 限制缩放范围
        fov = Cesium.Math.clamp(fov, minFov, maxFov);
        frustum.fov = fov;
    }, Cesium.ScreenSpaceEventType.WHEEL);

    // 显示退出按钮
    document.getElementById('exitPanoBtn').style.display = 'block';
}

// 定义函数：退出全景
function exitPanorama() {
    
    viewer.scene.globe.show = true;
    panoMarker.show = true;

    if (panoramaPrimitive) {
        viewer.scene.primitives.remove(panoramaPrimitive);
        panoramaPrimitive = undefined;
    }

    // 解除镜头的强制锁定
    const controller = viewer.scene.screenSpaceCameraController;

    controller.enableCollisionDetection = true;
    viewer.scene.camera.lookAtTransform(Cesium.Matrix4.IDENTITY);
    controller.enableRotate = true;
    controller.enableZoom = true;
    controller.enableTranslate = true;

    if (fovHandler) {
        fovHandler.destroy();
        fovHandler = undefined;
    }

    viewer.camera.frustum.fov = Cesium.Math.PI_OVER_THREE; // 恢复 60 度默认 FOV

    // 隐藏退出按钮
    document.getElementById('exitPanoBtn').style.display = 'none';

    // 镜头飞回
    viewer.camera.flyTo({
        destination: Cesium.Cartesian3.fromDegrees(panoLon, panoLat, 3000.0),
        duration: 2.0
```

```JavaScript
 function plantGrassInPolygon(viewer, jsonUrl, grassModels, totalGrass) {

    Cesium.GeoJsonDataSource.load(jsonUrl).then(function (dataSource) {
        const entities = dataSource.entities.values;
        let polygonPositions = [];

        // 提取面状数据所有拐点坐标
        for (let i = 0; i < entities.length; i++) {
            const entity = entities[i];
            if (entity.polygon) {
                const hierarchy = entity.polygon.hierarchy.getValue(Cesium.JulianDate.now());
                polygonPositions = hierarchy.positions;
                break;
            }
        }

        if (polygonPositions.length < 3) {
            console.warn("未找到有效面！");
            return;
        }

        // 将世界坐标 (Cartesian3) 转换为经纬度 (Cartographic/弧度)
        const cartographics = polygonPositions.map(point => Cesium.Cartographic.fromCartesian(point));

        // 计算包围盒的边界坐标
        let minLon = Number.MAX_VALUE, maxLon = -Number.MAX_VALUE;
        let minLat = Number.MAX_VALUE, maxLat = -Number.MAX_VALUE;

        cartographics.forEach(carto => {
            if (carto.longitude < minLon) minLon = carto.longitude;
            if (carto.longitude > maxLon) maxLon = carto.longitude;
            if (carto.latitude < minLat) minLat = carto.latitude;
            if (carto.latitude > maxLat) maxLat = carto.latitude;
        });

        // 通过任意一点的右射线，判断点是否在多边形内 
        function isPointInPolygon(point, vertices) {
            let x = point.longitude, y = point.latitude;
            let inside = false;
            for (let i = 0, j = vertices.length - 1; i < vertices.length; j = i++) {
                let xi = vertices[i].longitude, yi = vertices[i].latitude;
                let xj = vertices[j].longitude, yj = vertices[j].latitude;

                let intersect = ((yi > y) !== (yj > y)) && (x < (xj - xi) * (y - yi) / (yj - yi) + xi);
                if (intersect) inside = !inside;
            }
            return inside;
        }

        viewer.scene.globe.depthTestAgainstTerrain = true;
        let plantedCount = 0;
        let safetyCounter = 0;        // 限制最大数量，避免种植面积太小

        // 循环种树，直到达到目标数量或安全上限
        while (plantedCount < totalGrass && safetyCounter < totalGrass * 10) {
            safetyCounter++;

            // 在包围盒内随机生成一个坐标
            const randomLon = minLon + Math.random() * (maxLon - minLon);
            const randomLat = minLat + Math.random() * (maxLat - minLat);
            const testPoint = new Cesium.Cartographic(randomLon, randomLat);

            // 如果不在多边形内，直接跳过，重新生成随机点
            if (!isPointInPolygon(testPoint, cartographics)) {
                continue;
            }

            // 将经纬度转回世界坐标
            const surfacePosition = Cesium.Cartesian3.fromRadians(randomLon, randomLat, 0);

            // 随机选一种花或植物
            const randomModelIndex = Math.floor(Math.random() * grassModels.length);
            const selectedModel = grassModels[randomModelIndex];
            
            // 随机朝向
            const heading = Math.random() * Cesium.Math.TWO_PI;
            const hpr = new Cesium.HeadingPitchRoll(heading, 0, 0);

            // 添加Entity                        
            let orientation = Cesium.Transforms.headingPitchRollQuaternion(
                surfacePosition,
                hpr
            );
            viewer.entities.add({
                position: surfacePosition,
                orientation: orientation,
                model: {
                    uri: selectedModel,
                    scale: 1 + Math.random() * 0.5,
                    heightReference: Cesium.HeightReference.CLAMP_TO_GROUND,
                    castShadows: false,
                    receiveShadows: false
                }
            });
            plantedCount++;         // 成功种一株，计数器 +1
        }

        // 视角聚焦
        const centerLon = (minLon + maxLon) / 2;
        const centerLat = (minLat + maxLat) / 2;
        const customHeight = 1000;

        const destinationPos = Cesium.Cartesian3.fromRadians(centerLon, centerLat, customHeight);
        viewer.camera.flyTo({
            destination: destinationPos,
            duration: 5.0
        });

    }).catch(function (error) {
        console.error("数据加载失败:", error);
    });
}

const myGrassModels = [
    "./Data/CZML/Vegetation/Grass.glb",
    "./Data/CZML/Vegetation/Grass_2.glb"
];

const Json = "./Data/GeoJSON/Grass_bjfu.geojson";

plantGrassInPolygon(viewer, Json, myGrassModels, 500);
```
